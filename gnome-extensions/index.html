Made for GNOME Shell

Small extensions.
More personal desktop.

Bring useful menus to your top bar or let your wallpaper set the tone. Choose an extension below to get its install command.

First, get the extension sources

Run this once in a terminal. Then use an install command on either card.

git clone --depth 1 https://github.com/gcdias/gcdias.github.io.git "$HOME/gnome-extensions-source"

GNOME Menu

gnome-menu@gcdias

Add configurable menus to the top panel for apps, places, recent items, and handy system actions.

GNOME Shell 45–51

make -C "$HOME/gnome-extensions-source/gnome-extensions/gnome-menu" install

Gnome-Tint

gnome-tint@gcdias

Rotate picture-of-the-day wallpapers and tint the GNOME Shell interface to match their colors.

GNOME Shell 48–51

make -C "$HOME/gnome-extensions-source/gnome-extensions/gnome-tint" install
View source ↗

After installing: log out and back in to restart GNOME Shell, then enable the extension in the Extensions app if it is not already enabled. Each extension includes its own settings.
